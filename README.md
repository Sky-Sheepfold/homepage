## 站点彩蛋

[skycode.me](https://skycode.me) 是一个会跟着太阳换主题的主页，打开它试试：

- 它会按你身边的日出日落，自动在白天与夜晚主题之间切换；手动切换后，下一次日出或日落会准点回归自动模式。
- favicon 和头像会看你那边的天气：晴、多云、雨、暴风雨，再配上清晨、白天、黄昏、夜晚，从四套天空视觉里挑一套。
- 像素桌面上有慢慢飘的云、扫过的日光和一闪一闪的显示器；如果你偏好减少动效，它会安静下来。
